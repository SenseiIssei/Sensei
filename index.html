Fact retention

Retention is a necessary condition, not a sufficient one. It checks that every fact an agent would need — error locations, ids, values, signatures — is still literally present after compression. It does not prove a model answers correctly from the compressed text; that needs a model in the loop and is a separate, opt-in check.
